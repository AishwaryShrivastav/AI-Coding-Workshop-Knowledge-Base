## Notes

- **Data progression:** Days 1–2 use CSV files for speed. Day 3 onward, all labs connect to **live databases via MCP**.
- **Certification:** Attendance 20% · Lab outputs 30% · Capstone 40% · Post-training report 10%. Pass mark 60%.
- **Post-training support:** 3-month Q&A channel, bi-weekly office hours, code reviews for tools built at work.
